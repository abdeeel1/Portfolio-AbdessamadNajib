# 🚀 Professional Portfolio | Abdessamad Najib

A sleek, modern, and highly interactive developer portfolio. Built with a focus on **User Experience (UX)** and **Performance**.

<img width="1350" height="768" alt="image" src="https://github.com/user-attachments/assets/93ae21a6-4f91-48a1-ab47-b2d87cadd8ac" />



## 🛠️ Tech Stack
* **Framework:** React.js
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Deployment:** Netlify

## ✨ Key Features
* **Responsive Design:** Optimized for all screen sizes.
* **Fluid Animations:** Smooth transitions and scroll effects.
* **Modern UI:** Minimalist and clean aesthetic.

## 🚀 Local Development
1. Clone the repo: `git clone https://github.com/abdeeel1/Portfolio-AbdessamadNajib.git`
2. Install: `npm install`
3. Run: `npm run dev`
