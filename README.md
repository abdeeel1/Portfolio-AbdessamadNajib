# My Portfolio

A simple and modern personal portfolio built with React and Vite.

## 🚀 Features
- Responsive design  
- Sections: Home, About, Skills, Projects, Contact  
- Dark/Light mode  
- Download CV button  

## 🛠 Installation

npm run dev
